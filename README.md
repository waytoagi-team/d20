# D20 · Vibe Design

WaytoAGI 在 D20 全球设计院长峰会使用的动态网页演示稿。

## 主题

**Vibe Design：AI 时代的 Web Design 新范式**

从设计资产、社区内容与 Design.md 出发，展示网页、活动、OPC 产品、SEO 与商业流程如何进入同一套设计实践。

## 使用

直接打开 `index.html`。

- `→` / `Space`：下一页
- `←`：上一页
- `Home`：第一页
- `End`：最后一页

演示包含自动播放的网页录屏与产品视频，建议使用最新版 Chrome，并允许视频自动播放。
